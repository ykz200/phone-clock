# 活 · Clock

> Pixel 3a 桌面摆件时钟 · Solar Flare · 太阳耀斑

基于 Pixel 3a 设备二次利用的桌面摆件时钟 PWA 应用。单文件交付，无框架无依赖。

## v10.0 "Solar Flare" 新特性

- **Liquid Glass 6.0**：全新棱镜折射玻璃拟态系统（`--glass-prism` + `--glass-frost` + 弯曲变形变量），边缘光更均匀、对比度更出色
- **日冕辉光系统**：背景第七层 `bg-corona` 模拟太阳日冕的多层脉动光晕 + 太阳风粒子，根据昼夜自动调整强度
- **神经极光增强**：新增 `bg-neural-aurora` 极光波段系统，5条动态极光带以不同速度漂移，营造"气场"感
- **星群色彩漂移**：星云雾中的星星会根据时段产生微妙的色温偏移（±8° 色相），更有生命力
- **桌面预览 v10**：环境光动画速度提升、色温随昼夜渐变、设备呼吸光泽增强、hover 时的光晕反馈增强
- **SW 网络优先缓存**：缓存名称更新为 clock-v10-solar

## v9.2 "Drift · 浮游" 特性（继承）

- **桌面小水母「泡」**：钟面舞台里养了一只半透明水母，随天气与时段换心情 —— 晴天飘得快、雨天收触手、雾天发灰、雷暴发抖、22:00 后打 z；点它会缩一下并回话，整点会跳一次庆祝
- **绕边框巡游，不糊读数**：巡游目标点只在舞台四边那一圈采样，落点与直线路径都要过一遍实时矩形检测，压到钟面/翻页/状态栏就立刻换点；换钟面、转屏后一拍内自愈
- **可关**：设置 → 桌面小水母；禅模式与 AOD 下自动隐藏，`prefers-reduced-motion` 下静止
- **摆件字号字重整体上抬**：正文 13.8→14.7px 级、新闻标题与消息行改 600 字重，横屏小字对比度单独提亮一档（摆件是 40–60cm 外看的，细字在 OLED 上会发灰）

## v9 "Aura · 气场" 特性

- **Aura Glass v9**：全新彩虹边缘光系统（`.glass-iris` conic-gradient），玻璃卡片边缘随色温变化产生柔和的棱镜散射效果
- **Bio-Rhythmic 生物节律**：22:00-06:00 夜间所有动画自动放慢至 55% 速度，字重降至 300（更轻盈），全程无刺眼瞬变
- **Weather Mood Canvas**：背景第六层氛围系统（`bg-mood`），根据天气数据动态叠加情绪色温 — 晴暖金、雨冷蓝、雪亮白、雾灰蒙、雷暴偏紫
- **Weather Particles**：雨雪天气时渲染对应的柔和粒子效果（细雨、飘雪、迷雾），不影响主体内容
- **桌面预览 v9**：更真实的 Pixel 3a 机身体感 — 多方向环境光、桌面反射、hover 交互景深变化、设备的呼吸光泽
- **OLED Protection v9**：漂移幅度进一步缩小（±1.5/±1.2px），周期 50s，漂移路径经过平滑曲线过渡；小水母的巡游同时充当第二移动元素
- **信息密度渐进**：自动光感暗化更低（42%），夜间文字呼吸更柔和
- **视觉动效统一**：所有 `.glass-iris` 卡片共享缓慢旋转的棱镜散色动画，营造"气场"感

## v8.x 历史特性（继承）

- **资讯订阅**：每天定时抓取 RSS / Atom，去重后落到消息中心
- **代理链**：直连 → allorigins → corsproxy.io → codetabs，记忆成功通道
- **横屏摆件布局**：807×393 CSS px，时钟居左 + 消息/天气栏居右
- **一套 DOM 两套排版**：`.col` 在竖屏 `display:contents` 拍平，横屏恢复为真实弹性列
- **四模式切换**：数字 / 指针 / 文字 / Flip 翻页，滑动/滚轮/方向键/数字键切换
- **Circadian 节律背景**：24 小时色温插值系统，OKLCH 感知均匀色彩空间
- **星云雾多层背景**：Canvas 实时渲染 + 晨雾 + 整点脉动
- **智能感知**：环境光传感器、电池状态、自动省电模式

## 资讯订阅

设置 → 资讯订阅 可增删 RSS / Atom 源、改刷新时间、填代理前缀。每天到点抓取一次；开机补抓延迟 8 秒。

## 技术栈

- 纯 HTML + CSS + JavaScript 单文件
- Service Worker 离线缓存
- PWA 可安装
- 无构建工具 / 无 npm 依赖
- OKLCH 广色域感知色彩空间

## Pixel 3a 适配

- 打孔屏安全区（竖屏 34px 顶部 padding；横屏摆件归零并改为左右 20px 侧安全区）
- OLED 纯黑背景 (#000) + 像素漂移保护（±1.5/±1.2px，周期 50s）
- SDM670 SoC 友好的自适应帧率（省电模式 12fps / AOD 5fps）
- 环境光自适应亮度调节（42%-106%）
- 电池 <15% 自动省电模式
- 生物节律：夜间动画降速 55%，字重降至 300
