# 活 · Clock

> Pixel 3a 桌面摆件时钟 · Horizon · 地平线

基于 Pixel 3a 设备二次利用的桌面摆件时钟 PWA 应用。单文件交付，无框架无依赖。

## v11.0 "Horizon" 新特性

- **Liquid Glass 7.0**：流体玻璃升级 — 新增内部辉光层(`.glass-inner`)、更宽频的棱镜散射 conic-gradient、更柔和的三段式深度背景、更慢的虹彩旋转周期(140s)
- **Horizon Light v11**：全新背景层 `horizonCanvas` — 模拟地平线处的柔和光带，白天在地平线下方温暖处，夜间隐入上方偏冷色调，随昼夜相位连续变化位置/宽度/亮度
- **桌面预览 v11**：更真实的 Pixel 3a 机身细节 — 左上角打孔屏（准确位置）、右侧音量键+电源键（独立节点+阴影）、左侧 SIM 卡槽、屏幕反射层（右上渐变）、机身背面中框更细腻(1.4px border)+机身背面玻璃感
- **OLED Care 2.0**：用双轴正弦曲线（李萨如风格）替代随机跳变漂移，漂移连续不跳帧、±1.5px→±1.7px 振幅不变但过渡更平滑
- **Ambient 2.0**：新增 `_brightnessRAF()` 平滑亮度过渡专用 RAF 循环（3%步进插频），传感器数据不再突变到 CSS 变量
- **Circadian v11**：注释更新标注平滑插值意图，后续可扩展分钟子段
- **天气情绪 2.0**：色温精调 — 各天气码的饱和度降低约12%、透明度降低约15%，更不抢主体注意力
- **SW 网络优先缓存**：缓存名称更新为 clock-v11-horizon

## v10.0 "Solar Flare" 特性（继承）

- **Liquid Glass 6.0**：棱镜折射玻璃拟态系统（`--glass-prism` + `--glass-frost` + 弯曲变形变量），边缘光更均匀、对比度更出色
- **日冕辉光系统**：背景第七层 `bg-corona` 模拟太阳日冕的多层脉动光晕 + 太阳风粒子，根据昼夜自动调整强度
- **神经极光增强**：新增 `bg-neural-aurora` 极光波段系统，5条动态极光带以不同速度漂移，营造"气场"感
- **桌面预览 v10**：环境光动画速度提升、色温随昼夜渐变、设备呼吸光泽增强、hover 时的光晕反馈增强

## v9.x 历史特性（继承）

- **Aura Glass v9**：彩虹边缘光系统（`.glass-iris` conic-gradient），玻璃卡片边缘随色温变化产生柔和的棱镜散射效果
- **Bio-Rhythmic 生物节律**：22:00-06:00 夜间所有动画自动放慢至 55% 速度，字重降至 300（更轻盈），全程无刺眼瞬变
- **Weather Mood Canvas**：背景第六层氛围系统（`bg-mood`），根据天气数据动态叠加情绪色温 — 晴暖金、雨冷蓝、雪亮白、雾灰蒙、雷暴偏紫
- **Weather Particles**：雨雪天气时渲染对应的柔和粒子效果（细雨、飘雪、迷雾），不影响主体内容
- **桌面小水母「泡」**：钟面舞台里养了一只半透明水母，随天气与时段换心情
- **横屏摆件布局**：807×393 CSS px，时钟居左 + 消息/天气栏居右
- **四模式切换**：数字 / 指针 / 文字 / Flip 翻页，滑动/滚轮/方向键/数字键切换
- **Circadian 节律背景**：24 小时色温插值系统，OKLCH 感知均匀色彩空间
- **星云雾多层背景**：Canvas 实时渲染 + 晨雾 + 整点脉动
- **智能感知**：环境光传感器、电池状态、自动省电模式
- **资讯订阅**：每天定时抓取 RSS / Atom，去重后落到消息中心

```
BroadcastChannel('pixel3a-clock')
localStorage.clockV7Inbox
pushMessage(title, body, opts)
```

## 资讯订阅

设置 → 资讯订阅 可增删 RSS / Atom 源、改刷新时间、填代理前缀。每天到点抓取一次；开机补抓延迟 8 秒。

## 纸条变量

| 变量 | 含义 |
|------|------|
| `{worked}` | 已工作时间（从 8:30 起） |
| `{countdown}` | 距下班倒计时 |
| `{weather}` | 天气图标 |
| `{temp}` | 温度 |
| `{toFriday}` | 距周五天数 |
| `{sunrise}` | 日出时间 |
| `{sunset}` | 日落时间 |
| `{solar_term}` | 临近的二十四节气（3 天内） |
| `#quote` | 随机语录 |
| `#affirmation` | 随机自我肯定 |

## 技术栈

- 纯 HTML + CSS + JavaScript 单文件
- Service Worker 离线缓存
- PWA 可安装
- 无构建工具 / 无 npm 依赖
- OKLCH 广色域感知色彩空间

## Pixel 3a 适配

- 打孔屏安全区（竖屏 34px 顶部 padding；横屏摆件归零并改为左右 20px 侧安全区）
- OLED 纯黑背景 (#000) + 像素漂移保护（李萨如正弦漂移 ±1.7px，周期 ~50s）
- SDM670 SoC 友好的自适应帧率（省电模式 12fps / AOD 5fps）
- 环境光自适应亮度调节（42%-106%，2.0 平滑过渡）
- 电池 <15% 自动省电模式
- 生物节律：夜间动画降速 55%，字重降至 300
