# 活 · Clock

> Pixel 3a 桌面摆件时钟 · 四模式 · Circadian 节律 · 星云雾 · 智能感知

基于 Pixel 3a 设备二次利用的桌面摆件时钟 PWA 应用。单文件交付，无框架无依赖。

## v6 新特性

- **禅模式 (Zen Mode)**：长按时钟进入极简状态，仅显示时间，30分钟自动退出
- **更精细的 OLED 保护**：减幅像素漂移策略 + 屏保呼吸振动
- **柔光背景**：fractalNoise 纹理层 + 降低视觉对比度
- **玻璃拟态 v6**：多层内发光 + 柔和边框 + 低饱和色
- **天气联动**：实时光照/天气映射到界面色调
- **指尖触感**：长按触发禅模式时有振动反馈

## 特性

- **四模式切换**：数字 / 指针 / 文字 / Flip 翻页，支持滑动、滚轮、方向键、数字键切换
- **Circadian 节律背景**：24 小时色温插值系统，OKLCH 感知均匀色彩空间
- **星云雾多层背景**：Canvas 实时渲染（星云 + 氛围粒子 + 整点脉动 + 柔光噪声）
- **玻璃拟态 v6**：backdrop-filter + 多层叠加 + 微光边框
- **智能感知**：环境光传感器、电池状态、自动省电模式、时段分类
- **禅模式**：长按时钟进入极简状态，全 UI 淡出，30分钟自动恢复
- **桌面预览**：≥900px 自动进入 Pixel 3a 设备框架模拟
- **天气 / 空气 / 日出日落 / 月相**：Open-Meteo API，自动定位 + 缓存
- **专注统计**：双击启动专注模式 + 7 天热力图 + 连续天数
- **纸条轮播**：支持变量 + #quote / #affirmation 标签

## 技术栈

- 纯 HTML + CSS + JavaScript 单文件
- Service Worker 离线缓存
- PWA 可安装
- 无构建工具 / 无 npm 依赖

## 文件结构

```

├── sw.js               # Service Worker

└── README.md
```

## Pixel 3a 适配

- 打孔屏安全区（32px顶部 padding）
- OLED 纯黑背景 (#000) + 像素漂移保护
- SDM670 SoC 友好的自适应帧率
- 环境光自适应亮度调节
- 电池 <15% 自动省电模式
