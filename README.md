# 活 · Clock

> Pixel 3a 桌面摆件时钟 · 四模式 · Circadian 节律 · 星云雾 · 智能感知

基于 Pixel 3a 设备二次利用的桌面摆件时钟 PWA 应用。单文件交付，无框架无依赖。

## 特性

- **四模式切换**：数字 / 指针 / 文字 / Flip 翻页，支持滑动、滚轮、方向键、数字键切换
- **Circadian 节律背景**：24 小时色温插值系统，24 段色彩连续流动
- **星云雾多层背景**：Canvas 实时渲染（星云 + 氛围粒子 + 整点脉动）
- **玻璃拟态 v3**：backdrop-filter 多层叠加 + 微光边框 + 高光层
- **智能感知**：深夜自动降低对比度、时段分类（凌晨/清晨/上午/中午/下午/傍晚/夜晚）
- **桌面预览**：≥900px 自动进入设备框架模拟（景深/圆角/阴影/悬停动效）
- **天气 / 空气 / 日出日落 / 月相**：Open-Meteo API，自动定位 + 缓存
- **专注统计**：双击启动专注模式 + 7 天热力图 + 连续天数
- **纸条轮播**：支持变量（已工作时长、倒计时、天气、日出日落等）+ #quote / #affirmation 标签
- **世界时钟**：额外显示东京时间

## 技术栈

- 纯 HTML + CSS + JavaScript 单文件（~77KB）
- Service Worker 离线缓存
- PWA 可安装
- 无构建工具 / 无 npm 依赖

## 文件结构
